# myBank

## Overview
myBank is a simple banking system designed as a practice project to explore new technologies and enhance development skills. The app enables users to register, log in, and conduct transactions, including transferring money between accounts. It also features a *deposit* functionality to simulate adding funds to user accounts for practice purposes.

## Features
- **Account Registration and Login**: Securely create accounts and log in to access banking functionalities.
- **Transaction System**: Easily transfer money between accounts within the application.
- **Deposit Feature**: Add simulated funds to your account to test and explore the app capabilities.

## Purpose
This project is a collaboration between two workmates, aimed at experimenting with new technologies and reinforcing development skills in a fun and engaging way.

## Technology Stack
- **Backend**: ASP.NET Core (C#)
- **Database**: SQL Server (managed through Entity Framework Core)
- **Authentication & Authorization**: ASP.NET Identity with JWT Bearer tokens and cookie support
- **API Documentation**: Swagger (OpenAPI)
- **Object Mapping**: AutoMapper
- **Other Tools**: Custom Middleware, Dependency Injection
